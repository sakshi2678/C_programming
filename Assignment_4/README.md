# Assignment 4 – C Programming

## Description
This assignment contains C programs based on conditional statements and logical problem-solving using `if`, `else if`, and `else`.

## Programs

1. **Find the Greater of Two Numbers** – Compare two integers and determine which number is greater or whether both numbers are equal.
2. **Find the Greatest of Three Numbers** – Accept three integers and display the greatest number, including cases where two or all three numbers are equal.
3. **Check Leap Year** – Determine whether a given year is a leap year according to Gregorian calendar rules. Invalid years are handled.
4. **Calculate Student Grade** – Accept student marks and display the corresponding grade. Invalid marks are handled.
5. **Check Divisibility by 3 and 5** – Determine whether a number is divisible by both 3 and 5, only 3, only 5, or neither.
6. **Identify Character Type** – Determine whether a character is an uppercase alphabet, lowercase alphabet, digit, or special character.

## Technologies Used
- Language: C
- Compiler: GCC
- IDE: Visual Studio Code

## How to Compile and Run

Compile a program using GCC:

```bash
gcc Assignment4_1.c -o Myexe
```

Run the program on Windows:

```bash
Myexe.exe
```

Replace `Assignment4_1.c` with the required program filename.
