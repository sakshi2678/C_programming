# Assignment 5 – C Programming

## Description
This assignment contains C programs based on conditional statements, decision-making, and logical problem-solving.

## Programs

1. **Find the Greatest of Three Numbers** – Accept three integers and determine the greatest number, including cases where two or all three numbers are equal.
2. **Check Leap Year** – Determine whether a given year is a leap year according to Gregorian calendar rules. Invalid years are handled.
3. **Calculate Student Grade** – Accept student marks and display the appropriate grade based on the given criteria. Invalid marks are handled.
4. **Check Divisibility by 3 and 5** – Determine whether a number is divisible by both 3 and 5, only 3, only 5, or neither.
5. **Identify Character Type** – Determine whether a character is an uppercase alphabet, lowercase alphabet, digit, or special character.

## Technologies Used
- Programming Language: C
- Compiler: GCC
- IDE: Visual Studio Code

## How to Compile and Run

Compile a C program using GCC:

```bash
gcc Assignment5_1.c -o Myexe
```

Run the executable on Windows:

```bash
Myexe.exe
```

Replace the filename with the program you want to compile.

## Learning Outcomes
- Understand conditional statements in C.
- Develop logical thinking and problem-solving skills.
- Work with integers, characters, and floating-point values.
- Handle different input conditions.
- Practice compiling and executing C programs.
