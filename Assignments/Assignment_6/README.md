# Assignment 6 – C Programming

## Description
This assignment contains C programs based on conditional statements, decision-making, calculations, and real-world problem-solving.

## Programs

1. **Calculate Electricity Bill** – Accept electricity units consumed and calculate the total bill using slab-wise rates.
   - First 100 units: ₹5 per unit
   - Next 100 units: ₹7 per unit
   - Above 200 units: ₹10 per unit
   - Negative unit consumption is invalid.

2. **Check Admission Eligibility** – Accept student marks and age, then determine admission eligibility based on the given criteria.
   - Marks must be at least 60.
   - Age must be at least 17 years.
   - Negative age or marks outside 0–100 are invalid.

3. **Calculate Shopping Discount** – Calculate the final payable amount after applying a discount based on the purchase amount.
   - Below ₹1000: 0% discount
   - ₹1000 to below ₹5000: 10% discount
   - ₹5000 and above: 20% discount
   - Negative purchase amounts are invalid.

4. **Check Triangle Validity** – Accept three side lengths and determine whether they form a valid triangle. All sides must be positive, and the sum of any two sides must be greater than the third side.

5. **Calculate Employee Bonus** – Accept monthly salary and completed years of service, then calculate the bonus.
   - More than 10 years: 15% bonus
   - 5 to 10 years: 10% bonus
   - Less than 5 years: 5% bonus
   - Salary must be positive and years of service cannot be negative.

## Technologies Used
- Programming Language: C
- Compiler: GCC
- IDE: Visual Studio Code

## How to Compile and Run

Compile a program using GCC:

```bash
gcc Assignment6_1.c -o Myexe
```

Run the executable on Windows:

```bash
Myexe.exe
```

Replace the filename with the required program name.
